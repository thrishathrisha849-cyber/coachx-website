## How this manifest is used

1. Each row becomes `specs/0NN-slug/spec.md`, written using `.specify/templates/spec-template.md`, with **Functional Requirements extracted from the actual PRD requirement language** in the cited source file(s) — not paraphrased from `PRD_SUMMARY.md`.
2. Features flagged "Overlaps X" must have their spec's Assumptions section note the overlap and state which feature owns the canonical data model, per Constitution governance section.
3. `plan.md` / `tasks.md` per feature are a later phase (run per-feature when implementation on that feature actually starts), not generated in bulk alongside every spec.md.
4. Progress is tracked by updating the Status column in this file as each spec.md is completed.
