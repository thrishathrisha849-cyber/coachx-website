## How to use this file

When starting any future phase or feature that touches the database
layer, scan this table first. If the feature's requirements trigger one
of these gates, resolve it as part of that feature's own scoped work
(with its own justification and citations) — do not resolve it
speculatively in an unrelated phase, and do not let a gate's resolution
happen silently without updating this table.
